# Docker Infrastructure & Compose Configurations

This directory maintains multi-container deployment definitions for local and production deployment.

## Planned Services (To be implemented in Phase 8)

* `postgres`: PostgreSQL 17 data warehouse container with persistent volume storage.
* `fastapi`: Backend API & OAuth authentication service.
* `streamlit`: Analytical dashboard application.
* `airflow-webserver` & `airflow-scheduler`: Workflow orchestration engine.
